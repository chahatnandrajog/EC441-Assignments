# Week 6 – Practice Midterm 1

## Type
Problem

## Topics Covered
- Network delays (transmission, propagation)
- Shannon capacity and SNR
- Entropy and information theory
- CRC error detection
- Ethernet switching
- Multiple access protocols (ALOHA, CSMA/CD)
- Digital signaling

## Description
This artifact is a full-length practice midterm modeled after the structure and difficulty of Midterm 1. 
It includes multiple choice, short answer, and problem-solving questions across key topics from Lectures 1–8.

The goal was to simulate real exam conditions and reinforce problem-solving skills rather than just reviewing concepts.

## Reflection
Creating this midterm helped me understand how different networking topics connect together, especially how 
physical layer concepts like SNR impact higher-level performance like throughput. 

It also highlighted which areas require more practice, such as delay calculations and Shannon capacity problems.
