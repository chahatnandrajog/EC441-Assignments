# Week 10: Transport Layer, UDP, and Reliable Data Transfer

## Overview

This week’s artifact focuses on Lecture 18, which covered the transport layer, UDP, reliable data transfer, Stop-and-Wait, Go-Back-N, Selective Repeat, and how these ideas connect to TCP.

Since this lecture was formula-heavy and protocol-heavy, I created a problem set instead of a code lab. The goal was to practice both the calculations and the reasoning behind the formulas. I also made a formula sheet to explain when each formula should be used and what the variables mean.

## Files

- `formula-sheet.md`: Key formulas from the lecture with explanations and intuition.
- `problem-set.md`: Practice problems based on Lecture 18.
- `solutions.md`: Worked solutions with step-by-step reasoning.

## Topics Covered

- Transport layer multiplexing and demultiplexing
- UDP header fields and checksum purpose
- Stop-and-Wait utilization
- Bandwidth-delay product
- Required window size for pipelining
- Go-Back-N packet loss behavior
- Selective Repeat packet loss behavior
- Sequence number constraints
- TCP’s connection to GBN and SR
